# Isaia Lauritano – Luxury Travel Designer

This is a minimal, "quiet-luxury" website designed with HTML and Vanilla CSS.

## Features
- **Typography**: 
  - Headline: *SaolDispay-light* (Custom font)
  - Body/Subtitle: *AmoretSans* (Custom font)
- **Layout**: Full-screen hero section followed by minimal content sections.
- **Aesthetic**: Soft off-white background with subtle grain/noise reduction.
- **Animations**: CSS Keyframe animations for a smooth fade-down effect on load.

## Setup & Running

This project uses `vite` for a fast development server.

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Start Development Server**:
    ```bash
    npm run dev
    ```
    Then open the local URL provided (usually `http://localhost:5173`).

## Structure
- `index.html`: Main semantic structure.
- `style.css`: All syling, including font definitions and animations.
- `AmoretSans.ttf` & `cera-pro-regular.ttf`: Custom font files.
